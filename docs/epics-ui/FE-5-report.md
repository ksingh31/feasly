# FE-5 — Full report (S8)

**Goal:** the payoff. Every figure the engine returned, an honest AI narrative with its
disclaimer, and the interactive layer that makes the report sticky: what-if tiers,
re-runs, next steps, callback, partner sharing, PDF.

## Stories (build order)

### FE5-001 — Report: figures, breakdown, narrative, disclaimer
**Size:** M
**Description:** `/r/{token}` report layout: hero total range, cost rows (Land, Build,
Total + breakdown: site prep, foundation, framing, mechanicals, finishes, soft
costs — rendered only from the engine's `rows[]`, never invented), AI narrative with
the verbatim footer "Dollar figures are calculated deterministically from our cost
model — not generated by AI.", assessed-value context line, "Prepared {date}" stamp,
"Updated {date}" when ≥2 snapshots exist, "Estimate another address" (→ S1, keeps email).
Mock contract: `ReportSnapshot`.
**Acceptance criteria:**
- Rendered figures exactly match the mock's `ReportSnapshot` (contract test).
- Disclaimer footer present verbatim (copy-lint on the exact string).
- No invented line items — rows render iff the engine returned them.
- "Updated {date}" appears with ≥2 snapshots.
**Tests:** spec — contract rendering, snapshot-count header; UI — report layout.
**Mobile:** figures stack; breakdown becomes an accordion; hero range legible at 390px.
**Config notes:** disclaimer string + date formats from config.
**Dependencies:** FE4-003.

### FE5-002 — Tier what-if toggle + inline sqft re-run
**Size:** M
**Description:** Tier segmented control (Standard/Premium/Luxury) re-runs inline via
`POST /api/v1/estimates/{id}/revisions` — skeleton shimmer on figures, no reload, URL
stays `/r/{token}`. Sqft slider + "Re-run" likewise. Each re-run persists a new
immutable snapshot (mock appends; row count increments — no UPDATEs). Rapid toggling
debounces (300ms, from config) and cancels in-flight requests (last-write-wins).
**Acceptance criteria:**
- Toggle updates all figures without reload; URL unchanged.
- Each re-run adds a snapshot (count increments; immutability test).
- Race test: delayed responses resolve last-write-wins, no figure mixing.
**Tests:** spec — debounce, cancellation, immutability; UI — shimmer state.
**Mobile:** toggle ≥44px segments; slider thumb ≥44px; shimmer doesn't jank on mid-range Android.
**Config notes:** debounce ms from config.
**Dependencies:** FE5-001.

### FE5-003 — Next-3-steps checklist + callback request
**Size:** M
**Description:** "Your next 3 steps" checklist (1. Request a callback, 2. Talk to your
lender about construction financing, 3. Get a lot survey) — checkable, persisted per
`estimate_id` in `localStorage`. Callback panel: name prefilled, phone required here,
preferred window (Morning/Afternoon/Evening) → "Thanks — we'll call you {window}."
→ `POST /api/v1/reports/{token}/callback-requests`. Client never sees the team inbox
address (contract test asserts).
**Acceptance criteria:**
- Missing phone → inline error; success → exact "Thanks — we'll call you {window}." copy.
- Checklist state persists per estimate across reloads.
- Destination address absent from client bundle (grep test).
**Tests:** spec — validation, persistence; UI — panel layout.
**Mobile:** checklist checkboxes ≥44px; window chips thumb-friendly.
**Config notes:** step copy, windows, success string from config.
**Dependencies:** FE5-001.

### FE5-004 — Partner share + PDF (print stylesheet)
**Size:** M
**Description:** Partner share: email input → "Send" → fresh magic link scoped to the
same estimate (new `magic_links` row, same `estimate_id` in the mock) → inline
"Report sent to {email}." PDF: "Download PDF" → `window.print()` with a dedicated
`@media print` stylesheet (branded: wordmark, figures, assumptions, disclaimer,
"Prepared {date}"; hides nav/CTAs/checklist inputs).
**Acceptance criteria:**
- Share sends a scoped link (mock asserts same `estimate_id`, new link row).
- Print preview (headless Chromium) shows figures + disclaimer, hides chrome.
- "Report sent to {email}." exact copy on success.
**Tests:** spec — share contract; UI — print stylesheet via print-to-PDF snapshot.
**Mobile:** share form one-handed; print stylesheet tested from mobile layout too.
**Config notes:** share copy from config.
**Dependencies:** FE5-001.
